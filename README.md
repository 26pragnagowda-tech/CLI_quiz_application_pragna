CLI Quiz Application

Description

A command-line quiz application developed using Python. It loads questions from a JSON file, accepts user answers, calculates the score, and displays the final result.

Features

- Loads quiz questions from a JSON file
- Contains at least 10 questions
- Displays multiple-choice options
- Randomizes question order
- Accepts and validates user answers
- Calculates correct and incorrect answers
- Displays the final score and performance summary

Technologies Used

- Python
- JSON

Project Structure

CLI-Quiz-Application/
│
├── quiz.py
├── questions.json
└── README.md

How to Run

1. Install Python 3 on your system.
2. Keep "quiz.py" and "questions.json" in the same folder.
3. Open the terminal in that folder.
4. Run the following command:

python3 quiz.py

5. Enter A, B, C, or D for each question.
6. View your final score after completing the quiz.

Concepts Used

- Lists and dictionaries
- Functions
- Loops and conditional statements
- JSON file handling
- Randomization
- Exception handling
- Score calculation

Output

The application displays each question with four options, checks the user's answers, and shows the total questions, correct answers, wrong answers, and final percentage.
